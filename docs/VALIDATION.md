## 验证的行为

- 请求 URL、查询参数和原生认证保持不变；五种 User-Agent 模式均不补充额外认证或客户端专属字段。
- 按原生渠道 ID 应用身份，同地址的并发渠道、模型列表请求互不串用；保存一个渠道时保留其他渠道和全局重试配置。
- 包名、设置 ID、客户端模块及 CSS 前缀统一使用新名称。未配置的渠道使用原生身份，不读取旧版全局身份默认值。
- 渠道卡片合并身份与超时并置于全局配置上方，切换保留各自草稿。身份已保存、超时失败时明确提示部分成功，再次保存只提交未成功字段。
- 非成功 HTTP 响应原样返回，不消费错误正文、不自动选择身份；传输层每次只发起一次调用。
- 原生 Agent 统一管理有限重试、无限重试、固定间隔、可见进度、取消和自动继续上限。
- 工具参数、中文输出、交错工具调用、持久化记录和工具结果回放保持正确。
- 流空闲超时的原生默认值为 300 秒；仅有心跳时仍可超时。保存新值后，进行中的调用保留旧值，后续调用使用新值。
- 超时只保存所选渠道的字段，保留凭据引用、模型和其他渠道；过期 revision 被拒绝。
- 设置页在 320、480、680 像素内容宽度下没有横向溢出；卡片内控件左右留白至少 18 像素。
- 深浅色下拉菜单、键盘和鼠标选择、按模式显示说明、总开关/不限次数/零次数联动、配置保存和导航图标清理通过检查。

浏览器检查使用隔离页面，并复现了曾影响布局的宿主 CSS 规则；已查看生成截图。它不是正在运行的 Harness 设置窗口截图。
